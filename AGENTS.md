# Fluxo de entrega

- Ao concluir uma implementação ou correção solicitada, mantenha a documentação pertinente atualizada.
- Crie um commit com título descritivo e corpo que registre as mudanças, as validações executadas e as limitações relevantes.
- Faça o push para o branch de trabalho ao final, salvo orientação explícita em contrário do usuário.
- Inclua no commit apenas os arquivos relacionados ao trabalho realizado e preserve alterações independentes do usuário.
